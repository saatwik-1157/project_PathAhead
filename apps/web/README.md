# apps/web — the published site

Everything in this folder is served by Netlify as the site root
(`netlify.toml` → `publish = "apps/web"`), so `apps/web/about.html` is
`/about.html`, `apps/web/sw.js` is `/sw.js`, and so on. Nothing outside this
folder is reachable from the web. (This README itself is blocked with a forced
404 in `netlify.toml`.)

- No build step: edit a file and deploy.
- Links between files are relative, so the folder works from any static
  server: `python -m http.server 8000 --directory apps/web`.
- `*-roadmap.html` pages are generated by `roadmaps/build_roadmaps.py` —
  edit the generator, not the HTML.
- `js/config.js` holds public client keys only (Web3Forms form key; Supabase
  fields empty). Server secrets are Netlify environment variables.
- Bump `CACHE` in `sw.js` when you change files in its `CORE` precache list,
  and keep every entry in that list present, or offline install fails.
